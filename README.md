[TaskFlow IA
Aplicación web desarrollada como parte de la asignatura:

Generalización de Código de Automatización en Desarrollo de Software con IA

Descripción
TaskFlow IA es una aplicación para la gestión de tareas personales que permite:

Crear tareas.
Consultar tareas.
Modificar tareas.
Eliminar tareas.
Filtrar tareas por prioridad y estado.
Gestionar estados de avance.
Tecnologías Utilizadas
Backend
Python
Flask
SQLAlchemy
SQLite
Frontend
HTML5
CSS3
JavaScript
Instalación
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
Acceso
http://localhost:5000
